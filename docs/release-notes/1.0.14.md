# 1.0.14 — 毎回ちがう背景

アプリを開くたびに、タイトル画面で将棋部の誰かが出迎えてくれるように
なりました。背景に描かれた将棋盤も机に合った自然な大きさに描き直し、
AI の指し手のゆらぎが固定されていた問題も直しています。

## ハイライト

- **毎回ちがうタイトル画面。** 吉田先生と部員 5 人 (明・アリス・すず・
  ゆり子・テリー) が、それぞれの性格に合ったポーズで登場します。
  棋譜の本を読みこむ明、腕を組んでポーカーフェイスのアリス、手を
  振るすず、扇子を手に一礼するゆり子、窓の外を見つめるテリー。
  ごくまれに、加藤先生と吉田先生が夕暮れの廊下で談笑する特別な
  一枚が現れます。棋譜検討の一覧も同じ絵から選ばれます。
- **棋譜検討の背景も 2 種類に。** 再生画面はラーメン店と図書室の
  2 枚から選ばれます。
- **自然な大きさの将棋盤。** タイトル・対局・棋譜検討・詰将棋の
  背景に描かれた将棋盤が机いっぱいの大きさだったのを、実物らしい
  卓上盤の大きさに描き直しました。
- **AI の「気分」が本来の気まぐれさに。** 駒や盤を描くたびに乱数の
  種がリセットされていたため、弱いキャラクターの一手ごとの「気分」
  の抽選と思考時間のゆらぎが実質的に決まった並びになっていました。
  これを修正し、本来どおりランダムに働くようになっています。
