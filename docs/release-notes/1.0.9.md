# 1.0.9 — アクセシビリティ改善

タップしやすさ・読みやすさ・振動フィードバックを中心にした
アクセシビリティのまとめ直し。盤面の見た目や AI の強さは変わりません。

## ハイライト

- **ボタンと文字を大きく。** 720 px 基準のレイアウトでは 1 px が
  実機の約 0.57 dp にしかならず、これまでのボタン (40〜64 px) は
  Material の推奨 48 dp を大きく下回っていた。全画面のボタン・
  トグル・一覧行を 72 px 以上に、棋譜一覧や候補手の文字を 24 px に
  引き上げた。盤面の大きさは変わらない。
- **盤上の合図を色だけに頼らない。** 選択中の駒は金色の枠、移動
  可能なマスは緑の点で示すようにした。木目の上では半透明の色だけ
  では判別しづらく、色覚多様性のある方には見えないことがあった。
  ルール上指せないタップには赤いフラッシュと短い振動で「無効」を
  返す。
- **振動が実は動いていなかった不具合を修正。** 着手時の振動は
  実装されていたが、Android の VIBRATE 権限が無効のまま出荷されて
  いたため黙って失敗していた。
- **「アニメーションを減らす」設定を追加。** 盤の拡大縮小、駒の
  スライド、候補手パネルのフェードを即時にする。設定画面から
  切り替え可能。
- **王手・思考中の表示位置を変更。** 画面上端に固定していた
  「王手！」が Pixel 8a などのパンチホールカメラに隠れていたため、
  盤の直上に移動し、太字と白縁取りで読みやすくした。
- **スクリーンリーダー対応の第一歩。** 盤の各マスに「７六 歩 先手」
  のような読み上げ名を付け、記号だけだった棋譜再生のボタンにも
  日本語名を付けた。
