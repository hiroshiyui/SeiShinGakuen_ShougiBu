# 1.0.12 — 棋譜の自動保存と気分で変わる AI

対局が終わると棋譜が自動で残り、「棋譜検討」の一覧で誰といつ指して
どう終わったかが一目で分かるように。AI キャラクターは一手ごとに
「気分」が変わり、弱い相手でもたまに鋭い手を返します。

## ハイライト

- **棋譜の自動保存。** 詰み・千日手・持将棋・入玉宣言・投了のどれで
  終わっても .kif を自動で保存し、終了ダイアログにファイル名を表示。
  保存ボタンを押し忘れる心配がなくなりました。対局中の「棋譜」
  パネルからの途中保存はこれまでどおり。
- **「棋譜検討」の一覧が読みやすく。** ファイル名の代わりに、対局の
  日時・先手と後手・結果と手数 (例: 詰み 先手の勝ち・79手) を各行に
  表示。棋譜ファイルには終局理由と「結果：」行を記録するように
  なり、他のアプリで作った棋譜も末尾の記述から勝敗を推定します。
- **気分で変わる AI。** これまで各キャラクターの強さ設定は実際には
  使われておらず、Lv 1 は探索 8 回・温度 2.0 でほぼランダムに指して
  いました。キャラクターの設定を本当の強さの源にし、弱い相手ほど
  一手ごとに「気分」を抽選。普段はゆるく、ときどき鋭い一手を返す
  ので、初心者相手でも油断できません。Lv 1〜2 の最低探索量も引き
  上げました。
- **画面切り替えのフェード。** 各画面の切り替えを短い暗転でつなぎ
  ます。「アニメーションを減らす」をオンにすると即時切り替え。
