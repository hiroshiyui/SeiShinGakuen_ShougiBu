# 1.1.3 — 見やすく、押しやすく

画面のあちこちを実機で見直し、盤の大きさ、ダイアログ、設定、対局中の表示を
見やすく、押しやすくしました。中断中の対局を誤って消してしまう問題も直しています。

## ハイライト

- **先生モードで盤がきちんと縮むように。** 新しい対局で最初に
  「加藤先生！教えてください！」を押したとき、盤が縮まずに画面下のボタンが
  押し出されていた問題（Pixel 8a など縦長の端末）を直しました。詰将棋と
  棋譜検討も、カメラの切り欠きやジェスチャーバーの分を差し引いて盤の
  大きさを決めます。
- **中断中の対局を守ります。** 「続きから」がある状態で「新規対局」を
  押すと、確認なしに中断中の対局が消えていました。消す前に確認するように
  なりました。
- **直前の手が分かりやすく。** 状態表示の先頭に直前の手（例：「☖3四歩」）を
  表示し、そのマス目の色も濃くしました。AI の指し手を見落としにくくなります。
- **ダイアログと設定を押しやすく。** 終了・投了・削除などの確認ダイアログは
  題名を枠の中に収め、ボタンを大きくし、取り消せない操作では「いいえ」を
  最初に選んだ状態で開きます。対局モードなどの選択リストはゲームの配色に
  合わせて各項目を高くし、設定のスイッチは大きくして「オン」「オフ」を
  文字でも表示します。

そのほか、棋譜検討の解析中は「解析中… n / m」の文字がゆっくり明滅し
（「動きを減らす」設定では明滅しません）、棋譜の一覧ではいま表示している
手の行を塗りつぶして示し、持ち駒の枚数は駒の右上の小さな丸い印で表示する
ようにしました。選択リストを開いたまま戻る操作をすると終了の確認まで
開いていた問題も直しています。

## Linux 版の使い方

```bash
chmod +x seishingakuen-v1.1.3-x86_64.AppImage
./seishingakuen-v1.1.3-x86_64.AppImage
```

- インストール不要。ファイルマネージャーからダブルクリックでも起動できます。
- glibc 2.31 以降の x86_64 環境（Ubuntu 20.04 / Debian 11 以降）で動作します。
- 署名はありません。添付の `.sha256` で整合性を確認できます
  （`sha256sum -c seishingakuen-v1.1.3-x86_64.AppImage.sha256`）。
- 通信対戦では、ファイアウォールで UDP 47123・mDNS（UDP 5353）・
  TCP 47124〜47133 を許可してください。
- 配布は GitHub Releases のみで、itch.io と F-Droid は引き続き Android 版だけです。
