# 1.1.1 — Linux 版と、机のうしろの吉田先生

Linux デスクトップ版（x86_64 の AppImage）の配布を始めました。
タイトル画面の吉田先生の背景も、部員たちと同じ構図に描き直しています。

## ハイライト

- **Linux デスクトップ版。** このリリースから、Android 版の APK に加えて
  `seishingakuen-v1.1.1-x86_64.AppImage` を添付しています。AI 対局・
  棋譜検討・詰将棋・通信対戦（同じ LAN の Android 版とも対局可）まで、
  Android 版と同じ内容です。
- **吉田先生の新しいタイトル背景。** これまでは机に手をついて座って
  いたため、机の縁で腰から下が隠れていました。部員たちと同じように
  机の一歩うしろに立ち、両手を前で軽く組んでほほえむ姿になり、
  上半身がよく見えます。真珠のネックレスやブラウスのボタン、
  ワンピースのひだなど、服装の細部も廊下の背景の吉田先生に
  そろえました。

## Linux 版の使い方

```bash
chmod +x seishingakuen-v1.1.1-x86_64.AppImage
./seishingakuen-v1.1.1-x86_64.AppImage
```

- インストール不要。ファイルマネージャーからダブルクリックでも起動できます。
- glibc 2.31 以降の x86_64 環境（Ubuntu 20.04 / Debian 11 以降）で動作します。
- 署名はありません。添付の `.sha256` で整合性を確認できます
  （`sha256sum -c seishingakuen-v1.1.1-x86_64.AppImage.sha256`）。
- 通信対戦では、ファイアウォールで UDP 47123・mDNS（UDP 5353）・
  TCP 47124〜47133 を許可してください。
- 配布は GitHub Releases のみで、itch.io と F-Droid は引き続き Android 版だけです。
