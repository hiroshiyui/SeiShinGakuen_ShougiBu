# 1.0.13 — 表情が変わる対戦相手と詰将棋

対戦相手が対局の流れに合わせて表情を変えるようになり、将棋部らしさが
ぐっと増しました。短い時間で遊べる詰将棋 160 問、対局後の加藤先生の
一言、棋譜検討の形勢グラフも加わっています。

## ハイライト

- **表情が変わる対戦相手。** 8 人全員に「考え中・嬉しい・困った・
  勝ち・負け」の肖像を追加。AI の思考中は考える顔、形勢が良ければ
  嬉しい顔、苦しければ困った顔になります。王手をかけたり飛車・角を
  取ったりすると相手が一瞬たじろぎ、終局時の表情は対局終了
  ダイアログにも大きく表示。表情が読み取れるよう、盤面上部の肖像も
  一回り大きくしました。
- **詰将棋。** タイトル画面の「詰将棋」から、1手詰 40 問・3手詰
  60 問・5手詰 60 問に挑戦できます。「今日の一問」、使う駒を教える
  ヒント、やり直しつき。問題は AI 同士の対局から詰みのある局面を
  抽出した実戦詰めです。指した手は新しい詰み探索エンジンが判定する
  ので、手数内に詰ませる手順ならどれでも正解になります。
- **加藤先生の一言。** 対局が終わると、その対局でいちばん惜しかった
  一手と代わりの手を加藤先生が教えてくれます (例:「23手目の
  ☗４八銀 が惜しかったですね。☗３六歩 が良かったと思います。」)。
  「検討」ボタンでその手から棋譜検討を開けます。
- **棋譜検討の形勢グラフ。** 「解析」のあと、各手の先手勝率を棒
  グラフで表示。疑問手・悪手には印がつき、グラフをタップすると
  その手へ移動します。対局の流れが一目で分かるようになりました。
- **APK がむしろ小さく。** 肖像・背景・木目テクスチャの取り込みを
  非可逆 WebP に切り替え、肖像を 40 枚追加したうえで前バージョンより
  小さくなりました。
