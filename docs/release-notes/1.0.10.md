# 1.0.10 — タイトル書体と下端の余白

見出し用のポップ体を導入し、画面下端のジェスチャー領域に重ならない
余白を確保した小さな更新。盤面や AI の強さは変わりません。

## ハイライト

- **タイトルと見出しを Mochiy Pop One に。** メインメニューの
  「清正学園将棋部」、設定 / 棋譜検討 / 棋譜 / クレジットの見出し、
  対戦相手選択の名前、対局中の「王手！」を丸みのあるポップ体で
  表示するようにした。見出しにはタイトルと同じ黒の縁取りを付け、
  写真調の背景の上でも読みやすくしている。本文・ボタン・ダイアログ
  の書体はこれまでどおり Noto Serif JP / M PLUS 2。フォントは
  SIL OFL 1.1 で同梱し、必要な字形だけに絞って約 110 KB に抑えた。
- **画面下端にナビゲーションバー分の余白。** アプリは没入モードで
  動くため、Android はジェスチャー領域を安全領域として報告せず、
  これまでは下端の余白が固定の 32 px しかなかった。対局画面の手番
  表示やボタン、対戦相手選択の「戻る / 決定」、バージョン表示が
  ジェスチャー領域に寄りすぎていたので、上端のカメラ穴と同じ
  考え方で、ナビゲーションバー (48 dp) 相当の高さを下端に確保する
  ようにした。対戦相手選択画面も共通の計算を使うよう整理。
