# 1.0.7 — ダイアログの背景ぼかしと起動画面の修正

確認ダイアログの見せ方の改善と、1.0.6 の新アイコンで起きていた
起動画面の表示崩れの修正。

## ハイライト

- **ダイアログ表示中は背景をぼかすように。** 成り・投了・対局終了・
  入玉宣言・アプリ終了・棋譜削除の各ダイアログと棋譜一覧を開くと、
  後ろの盤面や背景がふわっとぼけて暗くなり、プレイヤーに選択を
  求めていることがひと目で分かるようにした。
- **起動画面のアイコンを修正。** Android 12 以降の起動画面では
  アダプティブアイコンの前景レイヤーだけが表示されるため、
  1.0.6 では教室の背景が抜けて二人だけが浮いて見えていた。
  前景に背景を合成し、起動画面でもアイコン全体が表示されるようにした。
