# 1.1.4 — 先生モードをなめらかに

先生モードの盤の拡大縮小をなめらかにし、加藤先生が考えている間は雲形の
吹き出しで知らせるようにしました。

## ハイライト

- **盤の拡大縮小がちらつかなく。** お薦めの手を開く・閉じるときに盤が
  縮む・戻る動きで、駒の文字やマス目が小刻みに揺れて見えていました。
  盤全体をひとつの絵として拡大縮小するようにし、なめらかに動きます。
- **閉じる動きもひと続きに。** 「閉じる」を押すと、お薦めの手が消えるのと
  同時に盤が元の大きさへ戻り、盤の下の段もなめらかに下がります。以前は
  段が一度に跳んでから盤が戻っていました。
- **先生の「考え中」は雲形の吹き出しで。** 「加藤先生！教えてください！」を
  押すと、先生のアイコンの上に「先生が考え中...」の吹き出しが出て、点が
  1 つ → 2 つ → 3 つと繰り返します。「動きを減らす」設定では点は動きません。

そのほか、README に効果音の出典とライセンスを明記しました。

## Linux 版の使い方

```bash
chmod +x seishingakuen-v1.1.4-x86_64.AppImage
./seishingakuen-v1.1.4-x86_64.AppImage
```

- インストール不要。ファイルマネージャーからダブルクリックでも起動できます。
- glibc 2.31 以降の x86_64 環境（Ubuntu 20.04 / Debian 11 以降）で動作します。
- 署名はありません。添付の `.sha256` で整合性を確認できます
  （`sha256sum -c seishingakuen-v1.1.4-x86_64.AppImage.sha256`）。
- 通信対戦では、ファイアウォールで UDP 47123・mDNS（UDP 5353）・
  TCP 47124〜47133 を許可してください。
- 配布は GitHub Releases のみで、itch.io と F-Droid は引き続き Android 版だけです。
