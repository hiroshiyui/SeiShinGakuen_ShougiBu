# 1.1.2 — あなたのアバター

将棋部の一員として、16 人の生徒から自分の姿を選べるようになりました。
盤の下に並んだあなたのアバターが、対局の流れに合わせて表情を変え、ひと言を話します。

## ハイライト

- **あなたのアバター。** 女子 8 人・男子 8 人の生徒から自分の姿を選べます。
  初回起動時に一度だけ選択画面が開き（「あとで」で後回しにできます）、
  設定の「アバター」からいつでも変更できます。対局中は盤の下に自分の
  肖像と名前が並び、対戦相手の肖像と名前は盤の上（相手の持ち駒の下）に
  移りました。
- **6 種類の表情。** 対戦相手と同じく、ふだん・思考中・嬉しい・困った・
  勝ち・負けの 6 つの表情があります。AI 戦では相手の表情と対になり
  （相手が嬉しそうならあなたは困った顔）、加藤先生が候補手を考えている
  間は考える顔に。通信対戦では、王手や飛車・角を取った瞬間に双方の表情が
  変わります。
- **あなたもひと言。** 対局開始や王手のときに、男女それぞれの言葉づかいで
  吹き出しにひと言が出ます。ひと言は自分の端末にだけ表示し、通信対戦の
  相手には送りません。
- **通信対戦の相手にもアバター。** 相手の画面には、あなたが選んだ
  アバターが表示されます（送るのは同梱の肖像のどれを選んだかだけです）。

そのほか、通信対戦のロビーの説明文を読みやすい大きさにし、詰将棋の
手数ボタンを押しやすい高さにしました。Linux 版は、スマートフォンに近い
縦長（432×960）のウィンドウで開くようになりました。

## Linux 版の使い方

```bash
chmod +x seishingakuen-v1.1.2-x86_64.AppImage
./seishingakuen-v1.1.2-x86_64.AppImage
```

- インストール不要。ファイルマネージャーからダブルクリックでも起動できます。
- glibc 2.31 以降の x86_64 環境（Ubuntu 20.04 / Debian 11 以降）で動作します。
- 署名はありません。添付の `.sha256` で整合性を確認できます
  （`sha256sum -c seishingakuen-v1.1.2-x86_64.AppImage.sha256`）。
- 通信対戦では、ファイアウォールで UDP 47123・mDNS（UDP 5353）・
  TCP 47124〜47133 を許可してください。
- 配布は GitHub Releases のみで、itch.io と F-Droid は引き続き Android 版だけです。
