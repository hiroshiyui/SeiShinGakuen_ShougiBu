# 1.0.15 — しゃべる部員たち

対局中に部員たちが吹き出しで話すようになり、対戦相手ごとの戦績も
残るようになりました。あわせて、プロジェクト全体のコードレビューで
見つかった不具合をまとめて修正しています。

## ハイライト

- **吹き出しでひと言。** 8 人それぞれが、対局開始・王手をかけたとき・
  飛車や角を取られたときに、肖像の下の吹き出しで話します。終局時の
  ひと言は対局終了ダイアログに表示されます。
- **あなたの戦績。** 対戦相手選択の画面に、その相手との勝敗数が
  表示されます。引き分けと、一手も指していない対局は数えません。
- **王手は玉のマスで。** 「王手！」の表示をやめ、王手をかけられた
  玉のマスが半透明の赤で示されるようになりました。
- **弱いキャラクターの指し手がまともに。** 読んでいない手をでたらめに
  指してしまう問題を修正しました。そのぶん Lv 1〜3 の相手は以前より
  手ごわくなっています。
- **棋譜検討の解析を改善。** AI が読まなかった手も正しく評価するように
  なり、解析中も画面が固まらなくなりました。
