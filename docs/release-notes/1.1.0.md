# 1.1.0 — 通信対戦

同じ Wi-Fi につながった友だちと、端末どうしで対局できるようになりました。
サーバーは使わず、インターネットにも接続しません。

## ハイライト

- **通信対戦。** 対局モードの「通信対戦」から対局を作ると、同じ LAN の
  もう 1 台に表示され、そこから参加できます。相手の発見には UDP
  ブロードキャストと mDNS（Bonjour）の両方を使うので、どちらかが届かない
  ネットワークでも見つかりやすくなっています。
- **後手は盤を回して。** 後手の端末では盤が 180° 回り、自分の駒が
  手前に来ます。
- **再戦と再接続。** 終局後は先後を入れ替えて再戦できます。通信が
  途切れても 60 秒以内なら自動で再接続し、対局を続けられます。
- **千日手を読む AI。** AI が千日手を読みに入れるようになり、連続王手の
  千日手で反則負けになる手順を繰り返さなくなりました。棋譜検討でも、
  千日手になる手は引き分け（連続王手なら負け）として評価します。
- **新しい権限について。** 通信対戦のために INTERNET と
  CHANGE_WIFI_MULTICAST_STATE の権限を使います。通信は同じ LAN の中だけで、
  インターネット上のサーバーには一切接続しません。広告・トラッキングも
  これまでどおりありません。

このほか、2 回のプロジェクト全体のコードレビューで見つかった不具合
（改ざんされた保存データへの耐性、画面上下の余白が大きすぎた問題、
「切れ負け」の棋譜の読み込みなど）と、通信対戦を終えると中断中の
AI との対局が消えてしまう問題を修正しています。
