# 1.0.6 — 新アイコンとエンジン更新

アプリアイコンの刷新と、ゲームエンジン・ビルド環境の更新。

## ハイライト

- **アプリアイコンを刷新。** 将棋部の中村アリスとテリー・クラークが
  教室の将棋盤の前に並ぶデザインに。Android のアダプティブアイコンを
  前景・背景の 2 レイヤーに分け、ランチャーのマスク形状 (円 / 角丸など)
  に関わらず二人の顔が欠けないようにした。
- **ゲームエンジンを Godot 4.7.2 に更新。** 対局ルール・AI の強さ・
  保存データはこれまでと同じで、既存のセーブもそのまま引き継げる。
