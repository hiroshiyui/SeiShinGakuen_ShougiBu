# 1.0.11 — 棋譜ダイアログの余白修正

1.0.10 で画面下端に確保した余白が、対局中の「棋譜」ダイアログだけに
効いていなかった問題の修正。それ以外の変更はありません。

## ハイライト

- **「棋譜」ダイアログの「保存 / 閉じる」がジェスチャー領域に重ならない
  ように。** このダイアログは固定の余白で全画面に重ねていたため、
  他の画面で下端に確保したナビゲーションバー分の余白が効いて
  いなかった。他の全画面と同じ安全領域の計算を使うように改め、
  上端のカメラ穴と下端のジェスチャー領域の両方を避けるようにした。
  全画面のシーンとダイアログを総点検し、残りは Godot 標準の中央
  表示ダイアログのみで影響なし。
